# ADR-003 —— 轨道切向驱动系数取 0.5 而非 v2 原值 2.0

## 背景

移植 v2 的轨道物理时，需要决定切向驱动系数 `tangentialK`。v2.3.1 的 `WorldConfig` 默认值是
`tangentialK = 2.0`。直接用该值后实测：球从 `orbitRadius=100` 的初始位置出发，
最终稳定在 **r=120**，即目标半径的 1.2 倍。

推演原因：切向驱动持续注入角动量，稳态下速度满足 `v = a·d/(1-d)`，而径向弹簧必须平衡
`v²/r`。因此平衡半径**必然大于** `orbitRadius`，偏移量随 `tangentialK` 单调上升：

| tangentialK | 稳态速度 | 平衡半径（目标 100） |
| --- | --- | --- |
| 0.05 | 0.27 | 100.0 |
| 0.1 | 0.54 | 100.2 |
| 0.5 | 2.70 | 103.9 |
| 1.0 | 5.40 | 114.2 |
| 2.0 | 10.80 | 120.0 |

## 选项

1. **保持 `tangentialK = 2.0`**：与 v2 数值一致。代价是平衡半径固定偏大 20%，
   正好卡在 S5 的验收线上。
2. **调低 `tangentialK` 到 0.5**：平衡半径偏大约 4%，轨道看起来是圆的。
3. **改径向弹簧为"目标半径为 1.2×orbitRadius"的补偿**：保持 2.0 的视觉速度，
   但让 `orbitRadius` 这个遗传参数的语义变成"名义半径"，与直觉不符。

## 决定

采用选项 2，`tangentialK = 0.5`。

理由：`orbitRadius` 是遗传参数，它的数值必须与其可观测后果一致，否则"变异涌现"无法解释——
一个基因说 100、实际半径 120，选择压力就作用在一个说不清的混合量上。
牺牲切向速度（2.70 而非 10.80）是可接受的：球仍然明确公转（实测 500 tick 内 10.09 圈）。

## 后果

正面：
- `orbitRadius` 成为可信的遗传参数，半径偏差约 4%。
- 与 S5 的 20% 阈值有足够余量。

负面：
- 与 v2 的数值不再一致，无法用 v2 的调参经验直接迁移。
- 公转速度较慢，视觉上不如 v2 活跃。

**遗留问题**：实测半径标准差与均值之比为 **0.356**，仍超过 S5 的 20% 阈值。
初步判断来自三处：球间排斥把球推离目标半径、核自身在移动、以及球在脱离/被拾取时
半径序列会跳变。此问题已登记为 TODO「正在进行」，尚未解决。

## 可逆性

**高**。`tangentialK` 是 `OrbitParams` 里的一个常量，改回 2.0 只需一行，且不涉及存档格式。
正因可逆性高，本 ADR 的价值在于记录**推演过程**（平衡半径必然偏移这一事实），
而不是锁定某个数值——后来者可以改数值，但不该再重复"以为调参没调好"的弯路。
