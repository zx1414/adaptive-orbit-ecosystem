agentsim 3.0.0 — 自适应环绕核生态模拟与生存游戏（发布包）
==========================================================

【启动】双击 agentsimw.exe
  不会弹黑框控制台，直接开独立应用窗口（Edge --app 模式）。
  已有实例在跑时，双击会复用已有窗口（单实例保护），不会开第二个。
  关闭窗口 = 退出模拟。

【玩法】
  菜单点「开始」→ 自动连上实时模拟。
  底部四轴滑杆（光照/蓝细菌/环境压力/生产者）拖动即生效，免费无限次。
  鼠标悬停任意核 → 弹出它的 24 个基因参数；点一下可钉住对比。
  快捷键：空格 播放/暂停 · R 视角复位 · F 影院模式 · H 折叠状态栏

【系统要求】
  Windows 10/11 x64，自带 Edge / WebView2 运行时（系统默认就有）。
  整个文件夹可拷贝到任何 Windows 机器运行，绿色免安装。

【注意】
  不要单独移动 agentsim.exe / agentsimw.exe 中的某一个——启动器需要同目录的 exe。
  frontend/ 目录必须与两个 exe 保持同级（前端页面从这里加载）。

【进阶】命令行用法：agentsim.exe --help
