## 文档结构

**§1 背景速览（≤半页）**——轨道范式一段话（球被动/核携基因组/十阶段管线）；五件基础设施一句话带过；红线声明：不得影响轨道范式逐字节基线，确定性/零和/枚举只追加等规矩沿用 MOD_SPEC。

**§2 目标与范式关系**——agent 范式定义（小球升级为 感知→决策→行为 自治体）+ 平行模式（`agent_mode` 开关，两套范式共存）。

**§3 Phase A0：四模块解耦（文档主体）**——

依赖方向图：环境→探测→决策→行为→账本，严格单向；决策不认识 World，行为是唯一可写点；全部收进 `namespace agentsim`。

每模块一节（职责 + 完整 C++ 接口签名 + 实现要点 + 落点文件）：

- **环境 `AgentEnvironment`**：SpatialGrid 双实例包装 + EnergyNode + 只读查询接口（可 mock）；
- **探测 `AgentSensors`**：**类型决定能力**——SensorProfile 由球类型给出（这是本轮新增的核心设计，直接落实"探测类球决定小球探测能力"）：
  - Scout 侦察 = 满配 8 通道 + 最大感知半径 + 最低噪声（群体的"眼睛"）；
  - Worker 资源 = 5 通道子集（最近能量点/自身能量/边界/局部密度）+ 短半径；
  - Shield 护盾 = 3 通道最小集 + 最短半径；
  - 感知半径/噪声再由基因在类型上限内缩放；
  - 契约形式：定长 8 维传感向量 + 类型能力掩码（未授予通道置零）+ typeOneHot 输入——决策器接口不因类型变长，v2 网络可无缝接管；
  - 纯函数契约 `sense(agent, env, profile, out)`；
- **决策 `IDecisionPolicy`**：接口 + v1 RulePolicy 参数表 + v2 NNetPolicy 接入路径（可替换性是核心验收）；
- **行为 `AgentBehavior`**：ActionIntent 值对象执行 + 复用 bounce() + 密度排斥占位；
- **账本 `AgentLedger`**：包装 EnergySystem，EnergyReason 末尾追加 AGENT_METABOLISM/MOVE/HARVEST；
- **管线编排 `WorldAgents.cpp`**：stepAgents 固定顺序伪代码 + `agent_mode` 分发；
- ParamSchema 追加键清单（~8 个）。

**§4 实施步骤**——Step 1-7（数据结构→环境→探测（类型能力表）→决策+StubPolicy→行为+账本→管线接入→冒烟），每步带编译与自验命令。

**§5 验收清单**——① agent_mode=0 基线逐字节一致；② agent_mode=1 双跑 stdout 一致；③ StubPolicy 注入跑通且探测/行为零改动；④ 类型能力掩码生效（Scout 传感半径显著大于 Shield，可用日志断言）；⑤ 零警告双口径；⑥ AGENT_* 科目出现在能量摘要。

**§6 路线图表**——A1 最小闭环（基因组/繁殖/平衡；类型能力从"探测"扩展到"行为"：Worker 采集加成、Shield 抗性/撞击）→ A1.5 蜂后式 CORE（菌落感知共享：Scout 持有数为菌落扩视）→ A2 状态机/小网络/攻击避让 → A3 建造/分享/频率依赖/有性重组。附三个关键决策结论与一句理由（规则表先行/核保留为菌落载体/局部感知）。
