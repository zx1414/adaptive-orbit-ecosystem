## 0. 三条物理定律

**定律一：能量只有一个入口，也只有固定的耗散出口。**

入口是蓝细菌的光合作用（每 tick 注入）。出口是各类耗散（呼吸、移动、死亡、溢出）。
除此之外**没有任何凭空产生或消失能量的通道**，连死亡掉下来的能量都有明确去向（70% 耗散、30% 变营养）。

**定律二：一切距离都是环面的最短距离。**

世界是一个左右相接、上下相接的环面。没有边界，所以"逃到角落躲起来"不存在，
"离边界多远"这个感知量在物理上**没有意义**，它只是坐标卷绕缝的距离。

**定律三：同一个种子加同一串操作，等于逐字节相同的世界。**

任何一次演化都能精确复现。这不是"大致一样"，是输出文件逐字节一致。
你要做对照实验，这是最狠的工具：**改一个旋钮，其他全不变，跑两次，差异全部来自那个旋钮**。

## 1. 空间：环面与边界的幻觉

世界尺寸默认 W = H = 1024，面积是早期 256x256 版本的 16 倍，蓝细菌、核、初始种群都按面积等比放大。

**最小环距**（所有距离判定的唯一口径）：

```
dx = bx - ax;   若 |dx| > W/2 则 dx = dx -/+ W
dy = by - ay;   若 |dy| > H/2 则 dy = dy -/+ H
d(a,b) = sqrt(dx^2 + dy^2)
```

两点最远只可能相距对角半宽（默认约 724 世界单位）。
所有"找最近的 X""造线""遮光""捕食判定"都走这个距离，没有一个地方用直线距离。

**坐标卷绕**：任何位移结束后位置都被 wrap 回 [0,W) x [0,H)。
所以一个核从 x=1020 往右走 10 个单位，会出现在 x=6。视觉上是"左出右进"。

**重要推论**：世界没有角落。一个核无论走到哪，周围的结构都等价。
`离最近边界距离`（感知维 s13）在环面上不提供任何生存信息。

## 2. 阳光：全图唯一的能量水龙头

### 2.1 公式

每 tick 计算一个**全局标量** S：

```
S = clamp01( baseLevel - verticalGradient*(y/H)              // 基础项
           + dayAmplitude * sin(2*pi*t / dayPeriodFrames)    // 昼夜项
           + noiseAmplitude * (hash01 - 0.5) )               // 噪声项
```

默认值：

| 参数 | 默认 | 含义 |
|---|---|---|
| baseLevel | 0.5 | 基础光强（全天均值） |
| dayAmplitude | 0.5 | 昼夜振幅 |
| dayPeriodFrames | 628 | 昼夜周期（帧） |
| verticalGradient | 0（关闭） | 垂直梯度系数 |
| noiseAmplitude | 0（关闭） | 阳光噪声幅度 |

所以默认曲线就是 S(t) = 0.5 + 0.5*sin(2*pi*t/628)：周期 628 tick，S 在 [0,1] 之间完整摆动。
**一次完整昼夜约 628 tick**，以 60fps 实时跑约 10.5 秒。

### 2.2 关键事实：光是全局的，不是局部的

生产路径调用时 y 传的是世界高度 H，所以：

- **垂直梯度退化为常数压暗**：y = H 时 base = baseLevel - verticalGradient。
  整幅世界统一变暗，**不产生上下差异**。
- **噪声退化为每 tick 一个标量**，与位置无关。

这意味着：**你不能通过"把蓝细菌种在向阳坡"来获得优势**。空间上的光照差异不进入生态收支。

> 这是当前实现的一个明确限制，不是你的操作失误。

### 2.3 阳光的实际作用：决定光合的饱和程度

核心是**次线性饱和**：光越强，单节点光合收益的边际增量越小。
S 从 0.5 涨到 1.0，单节点光合从 0.5 涨到 0.667，**翻倍的光只换来 33% 的产出**。

## 3. 蓝细菌：生产者与唯一的食物

蓝细菌节点是环境层实体。它是这个世界的**唯一能量入口**，也是核的**唯一食物**。
节点一旦出生，**位置永不移动**，它们是固定的"植物"。

### 3.1 节点状态

每个节点只有四个量：位置（固定）、能量 E、存活标志、遗传色相 hue 在 [0,360)。
初始能量恒为 **0**，能量只能从光合长出来。

### 3.2 播种：64 个聚落、512 个节点

**聚落模式**（生产默认，64 个聚落）：

1. 撒 64 个聚落中心，全图均匀：`c_i = (U1*W, U2*H)`
2. 每个节点归属某个聚落（轮转 i mod 64），在圆盘内均匀撒点：
   ```
   theta = 2*pi*U3
   r     = clusterSpread * sqrt(U4)
   pos   = c_(i mod 64) + r*(cos theta, sin theta)
   ```
   sqrt(U) 保证**面积均匀**（不是半径均匀，否则会向中心堆积）
3. 色相：`hue = 360*U5`

默认 clusterSpread = 45，所以每个聚落是半径 45 的圆盘，512 个节点摊在 64 个簇里。
**这形成真实的斑块状植被格局**，这是自遮光机制有意义的前提（均匀撒点下自遮光几乎不起作用）。

### 3.3 每 tick 的七段流水线

顺序**固定**（这是确定性的核心）：

| 段 | 动作 |
|---|---|
| 1 | 光合（每个存活节点） |
| 2 | 代谢 + 饿死判定 + 能量截顶 |
| 2.5 | 连线能量再分配（按 linkCheckInterval 节流，默认每帧） |
| 3 | 产球判定（每存活节点 1 抽） |
| 4 | 产球位置（每产球节点 2 抽） |
| 5 | 分裂判定（每存活节点 1 抽 + 通过者 2 抽高斯） |
| 6 | 分裂位置（每亲代 2 抽）+ 间距校验 |
| 7 | 移除尸体、帧计数 +1 |

死节点在所有判定段直接跳过、**不消耗随机数**。

### 3.4 光合：Michaelis-Menten 饱和加自遮光

对每个存活节点 i：

```
L_i      = S * exp(-shadeK * shade_i)                              // 局部光照，被打折过的
gain_i   = photosynthesisRate * L_i / (L_i + lightHalfSaturation)  // MM 饱和
room_i   = max(0, energyCap - E_i)
credited = min(gain_i, room_i)
E_i     += credited
```

**三个必须理解的数字**：

1. **单节点光合上界** gain <= photosynthesisRate = 1.0，而实际满光（S=1）时是 1.0 * 1/(1+0.5) = **0.667**。
2. **满光单节点净增长** = 0.667 - 0.02 = **0.647** 能量/tick。从 0 涨到 energyCap=100 约需 **155 tick**。
3. **封顶后注入为 0**：节点攒满 100 就不再接受能量（credited 而非 gain 入账）。这防止了能量凭空堆积。

**自遮光**（生态负反馈的物理来源）：

```
shade_i = sum over j != i, j alive, d_ij < shadeRadius:
              exp( -d_ij^2 / (2 * shadeSigma^2) )
```

参数：**shadeK = 0.20**（生产值；模块默认 0.05）、shadeRadius = 60、shadeSigma = 30。

直觉：**节点越密，每个节点分到的光越少**。一个孤立节点 shade 约 0；
紧挨着 3 个邻居时 shade 约 3，`L_i = S*exp(-0.6) = 0.549*S`，光合降约 23%。

这就是**自疏（self-thinning）**：密度上升，单位产量下降，分裂停滞，密度回落。
这是整个生态系统**唯一的内生负反馈**，也是"种群不会无限爆炸"的真正原因（不是任何硬上限）。

> **调参心法**：想观察自然稀疏，把 shadeK 往上调；想让生产端彻底失控，调到 0。
> shadeK = 0 时整个系统的承载力就只剩 cyanoMaxNodes 这个性能护栏了。

**一帧滞后**：光合读的是**上一结算帧**缓存的 shade_i。因为节点位置永不移动，
滞后只来自帧间存活集合变化（新节点/死亡节点延迟一帧计入），量级可忽略。

### 3.5 代谢与饿死

**线性常数型**代谢（不是能量加权）：

```
E_i -= metabolismRate          // 0.02
```

若扣完 E_i <= 0 则**饿死**：能量归零、标记死亡、本帧末移除。
实际耗散 = 死前剩余能量 + 0.02（账目精确，不留残值）。

若 E_i > energyCap = 100（仅外部注入可能造成），截顶到 100，截掉的部分**不记入任何账目**（纯状态归一）。

### 3.6 连线：富节点补贴穷节点

每 linkCheckInterval（默认 1，即每帧）执行一次拓扑重算加能量再分配。

**成边规则**：两个节点要**双向互选**才成边。
每个节点在 linkRadius = 60 内按（距离，对方下标）升序排序，取前 linkMaxNeighbors = 3 个作为候选。
只有 i 选了 j **且** j 也选了 i 时才成边。

**能量传输**：对每条边，设两端能量为 Ea, Eb，diff = |Ea - Eb|：

```
amount = diff > linkDeadband(=1.0) ? diff * linkTransferRate(=0.1) : 0（跳过）
E_hi -= amount;   E_lo += amount
```

linkTransferRate = 0.1 意味着每次传输把 10% 的能量差拉平，指数收敛，不会瞬间拉平。
**死区 1.0** 防止微小差异来回抖动。

**零和**：这是纯内部再分配，不进账本、不产生也不消耗能量。

**生态意义**：簇内能量被拉平，等于**整簇共担风险**。
一个节点在丰产季积累的能量会流向簇内穷邻居，让整个簇更难被饥饿击穿。
这是**蓝细菌版的社会性**，而且是免费的（零能量成本）。

### 3.7 产球：生产者自己也会吐球

每存活节点抽 1 次 U：

```
U < ballSpawnProbability(=0.02) 且 E_i >= ballSpawnCost(=30)
  => E_i -= 30, 在节点附近产一个自由球
```

出生位置：距产者 [10, 30] 随机距离、随机角度，wrap 回环面。
球的初始能量 = 30 * ballRadius = 30（ballRadius 必须保持 1.0，否则账目失衡）。

> **注意这是两套产球机制之一**：蓝细菌会自己吐球（免费能量散落到世界），
> 核也会主动产球（花自己的能量造器官）。两者物理上都是自由球，但对生态意义完全不同。

自由球池**上限 256**，超限时回收**最老的蓝细菌源球**并全额耗散（reason cyanoBallExpire）。
这是防能量坟场的护栏，否则世界里会堆满没人捡的球。

### 3.8 分裂繁殖：70% 近、30% 远

每存活节点抽 1 次 U：

```
U < reproductionProbability(=0.01)
  且 节点数 < cyanoMaxNodes
  且 E_i >= reproductionCost(=40)
```

通过后立刻再抽 2 次数构造高斯抖动（**无论间距是否放行都消耗**）。

**子代位置**：1 次 U 单抽映射到两段半径（近段概率质量 0.7）：

```
nearSpan = 0.5 * reproductionOffset = 62.5

r = U < 0.7  ? (U/0.7) * 62.5                          // 70% 落在 [0, 62.5)
    :          62.5 + ((U-0.7)/0.3) * (125 - 62.5)     // 30% 落在 [62.5, 125)

theta = 2*pi*U2
位置 = 亲代 + r*(cos theta, sin theta)
```

**间距校验**：对全部存活节点（亲代豁免、同帧兄弟计入）求最小环距，
若 < minSeparation = 10 则**放弃本次分裂**，不扣能量、不记损失，但随机数照抽。

**能量分割**：亲代 -40、子代 +20、**另 20 记作耗散**（reason cyanoReproduction）。
这 50% 的分裂损耗是真实的（建造成本），不是记账技巧。

**生态意义**：r 的双段分布让近亲扎堆（70%）又偶尔远距离殖民（30%）。
配合自遮光，形成"簇内过度拥挤，近亲子代被遮蔽饿死，30% 远距离后代找到空地"的动态。

### 3.9 捕食：核怎么吃节点

在**组合根**里执行（核处理完之后）。三级闸门：

1. 核活着
2. cyanoPreference > 0（**严格的 0 哨兵：基因恰为 0 的核绝不捕食**）
3. digestCooldown == 0（处理时间约束）

**目标选择**：cyanoPredationRadius = 14 内**最近**的存活节点，确定性平方距离扫描，无随机。

**每口请求量**：

```
want = cyanoPreference * grazeBiteFraction * E_prey
     = cyanoPreference * 0.15 * E_prey
```

注意：**与核自身能量无关**。饿核和饱核吃同样多。这是刻意的，欲望由基因决定，不由饥饿感决定。

**转化率**（默认 conversionMode = 1，速度惩罚）：

```
rate = conversionRate * cyanoDigestion * speedRef/(speedRef + maxSpeed)
     = 0.6 * cyanoDigestion * 40/(40 + maxSpeed)
```

然后钳到 [0.05, 1.0]。

| maxSpeed | 转化率（cyanoDigestion=0.55） |
|---|---|
| 30 | 0.33 * 0.571 = **0.188** |
| 65（默认） | 0.33 * 0.381 = **0.126** |
| 100 | 0.33 * 0.286 = **0.094** |
| 300（上限） | 0.33 * 0.118 = **0.039** |

**这是整套系统最重要的取舍之一**：跑得快的核**捕食转化率更低**。
快等于探索范围大但吃得少；慢等于吃得香但覆盖小。这个权衡是速度基因能分化的根源。

**捕食避难所**：节点保留 grazeRefugeEnergy = 15 不可食：

```
avail = max(0, E_node - 15)
taken = min(want * rate, avail)
```

所以**节点永远不会被吃死**（只会饿死）。这是捕食者-猎物稳定共存的标准条件（refuge），
也是"蓝细菌不会灭绝"的硬保证。

**实际取得**：`E_核 += taken`，账本记 `transfer(节点 -> 核, taken)`（零和搬运）。
**没吃到的部分根本没有离开节点**，不存在"咬一口浪费一半"的二次损耗，同化效率就是 rate 本身。

**处理时间**：吃完一口进入冷却

```
digestCooldown = ceil( 1 / (0.5 + cyanoDigestion) )
```

| cyanoDigestion | 冷却（帧） | 每秒最大进食次数（60fps） |
|---|---|---|
| 0.1 | 2 | 30 |
| 0.55 | 1 | 60 |
| 1.0 | 1 | 60 |

冷却**不耗能**，它是"嘴里还嚼着"的物理约束。

### 3.10 营养循环：尸体到分解者到植物

核死亡时能量分两路：**70% 当场耗散**（death），**30% 装成尸体营养包**。

每个营养包在 kCarrionSearchRadius = 200 内找最近的存活节点：

- 接受量 = min(amount, energyCap - E_node)，记 `transfer(0 -> 节点, accepted)`
- 溢出部分（节点装不下）记 `dissipate("death")`
- 半径内无节点则全额 `dissipate("death")`

这是真实养分循环（动物尸体到分解者到植物）。**效果**：核密集区死后会长出一片蓝细菌，
吸引新的核，形成斑块动态（patch dynamics）。这是这个模拟里最"活"的机制之一。

**能量绝不滞留**：每个营养包要么进了节点，要么被明确耗散，账目逐包闭合。

### 3.11 死亡与移除

| 通道 | 条件 | 能量去向 |
|---|---|---|
| 饿死 | 代谢后 E <= 0 | 死前能量全额耗散 |
| 被捕食抽干 | **仅在 grazeRefugeEnergy <= 0 时可达** | 同饿死 |
| 移除 | 每帧末压缩尸体槽 | 尸体能量必为 0 |

生产值 grazeRefugeEnergy = 15，所以**捕食通道永远不会杀死节点**。

## 4. 核：能量、容量和 24 个基因

### 4.1 它有什么

| 状态 | 含义 |
|---|---|
| pos / vel | 环面坐标与速度 |
| energy | 体能（与球里的能量分开计量） |
| cap | **菌落容量**，能量上限，每帧末重算 |
| balls | 名下球，最多 3 个 |
| genome | 24 个可遗传参数加 hue |
| digestCooldown | 消化冷却 |

### 4.2 它**没有**什么（重要）

- **没有质量、没有半径、没有朝向**
- **没有年龄**（不会老死，唯一死法是能量归零）
- **没有谱系编号**（没有 parentId / generation）
- **没有战斗能力**（核与核之间零能量转移）

"体型"这个概念由 cap（容量）代表。"长大"在实现上等价于：
**能量积累，触发产球，Resource 球抬高 cap，能装更多能量**。

### 4.3 容量经济学：为什么必须囤球

```
cap = nativeCap + sum(Resource 球的 cap)
    = 200 + 60 * n_resource
```

| Resource 球数 | cap |
|---|---|
| 0 | 200 |
| 1 | 260 |
| 2 | 320 |
| 3（上限） | 380 |

**超出 cap 的能量立即被裁剪销毁**（reason capOverflow），不留到下一帧。

**繁殖门槛**是 genome.energyThreshold（初始区间 [80,200)，钳制 [20,1000]），
默认基因值约 140。所以：

- 门槛 140 小于原生容量 200：**不囤球也能繁殖**（默认基因）
- 但如果基因演化出 energyThreshold 大于 200（变异允许到 1000），**就必须先囤 Resource 球**才够本繁殖

这就是"球作为储能仓库"的机制：**它不是可选的装饰，而是高门槛基因型的硬需求**。
高能量门槛的核必须放弃 1 到 3 个球位给 Resource 球，这挤占了 Scout（感知）和 Shield（护盾）的位置，
一个真实的资源分配难题。

### 4.4 三类球

| 类型 | 作用 | 关键数字 |
|---|---|---|
| **Resource** | 贡献容量 | 每球 +60 cap |
| **Scout** | **唯一感知来源** | 见下 |
| **Shield** | 降低呼吸 | 呼吸基础项 / (1 + 0.35 * n_shield) |

**侦察球是感知的唯一来源**，这是用户明确纠正过的语义，不可回退：

```
R = 0.25 * R_base = 6                        // n_scout = 0（原生盲区）
R = min( R_base * sqrt(1+n),  4*R_base )     // n_scout = n > 0
```

R_base = senseRadius = 24。

| Scout 数 | 有效感知半径 | 相对盲区 |
|---|---|---|
| 0 | **6** | 1x |
| 1 | 24*sqrt(2) = **33.9** | 5.65x |
| 2 | 24*sqrt(3) = **41.6** | 6.93x |
| 3（上限） | 24*2 = **48** | 8x |

**资源球对感知零影响**。不是"囤资源就失明"，而是"囤资源不帮忙看路"。
这是一个纯粹的取舍：球位有限（3 个），你要感知、要容量、还是要护盾。

## 5. 感知：24 维世界进入核的脑子

感知层是**纯函数**：只读环境，不写任何状态。输出 24 维向量 s0...s23。

### 5.1 前 10 维：蓝细菌候选

在有效半径 R 内找**最近的 3 个存活节点**（升序，无加权），对第 i 个候选：

```
s[2i]   = dx_i / d_i                          // 方向单位向量
s[2i+1] = dy_i / d_i
s[6+i]  = clamp01( 1 - d_i/R )               // 接近度：贴着是 1，在半径边缘是 0
s[9]    = min(1, d_0/R)  （无候选时为 0）      // 最近节点归一化距离
```

**聚合方式是最近 3 个**，不是求和、不是加权平均。第 4 近的节点完全不可见。

### 5.2 中 8 维：自身状态

| 维 | 公式 | 含义 |
|---|---|---|
| s10, s11 | vx/(1+v), vy/(1+v) | 速度分量 |
| s12 | v/(1+v) | 速度模长（归一化到 [0,1)） |
| s13 | clamp01(min(x, W-x, y, H-y) / (0.5*min(W,H))) | **距坐标缝距离**（环面上无物理意义） |
| s14 | amp | 本帧读噪声幅度（元信息，不是随机数） |
| s15 | 0 | 保留 |
| s16 | temp.distortion(pos) | 温度失真度 |
| s17 | clamp01(temp.sample + terrain.temperatureOffset) | 归一化温度 |

s13 值得单独强调：在环面拓扑里**不存在边界风险**。
这个维度的实际用途只有 ForageBank 策略把它当能量代理，而那是个设计缺陷。

### 5.3 后 6 维：社会与施力（R2 新增）

| 维 | 公式 | 无信息时的哨兵值 |
|---|---|---|
| s18 | clamp01(d_nbr / nucleusSightRadius) | 1.0 |
| s19, s20 | 邻居方向单位向量 | 0, 0 |
| s21 | clamp01(E / cap) | 0 |
| s22 | targets.count / 8 | 0 |
| s23 | clamp01(d_ball / R) | 1.0 |

**这个尾部是零 RNG 的确定性计算**，不受噪声影响，策略可以完全信任它。

### 5.4 读噪声：速度与温度的双重污染

```
amp = k_readNoiseK * v/(1+v) * (1 + k_tempGain * d)
    = 0.15       * v/(1+v) * (1 + 3.0 * d)
```

| 条件 | amp 上界 |
|---|---|
| 静止 | **0**（完全干净） |
| 全速加无失真 | 0.15 |
| 全速加满失真 | **0.6**（放大 4 倍） |

噪声**逐候选独立抽取** 3 个 U(-amp, +amp)，分别加到方向分量和接近度上：

```
s[2i]   += ax
s[2i+1] += ay
s[6+i]   = clamp01( s[6+i] + ap )
```

加噪后 s[0..5] **重新归一化**为单位向量（保证决策层点积语义不被破坏）。
s9 有独立的噪声通道（1 次抽取）。

**关键设计点**：**静止的核感知是绝对准确的**。噪声是运动与不适温度的代价，不是环境本身的随机性。
这意味着"停下来看清楚"是一个真实可行的策略。

**RNG 消耗**：每帧至多 3*3+1 = 10 次；amp = 0 时**一次都不抽**。

## 6. 决策：8 套生存哲学的完整算式

### 6.0 公共契约

所有策略遵守同一组红线：

- **不用 RNG**（决策期零随机），同输入必得同输出
- **不读世界**（只消费传入的 24 维向量和目标清单）
- **不写实体**（只返回意图，校验和扣费全在行为层）
- **NaN 安全**（非有限输入一律清洗，全 NaN 输入不产生 NaN 输出）

**最重要的全局事实**：整个仿真**只持有一个策略实例**，所有核共享它。
所以**有状态的策略（Hysteresis / ForageBank / Bandit / RiskAverse）的内部记忆是全种群共享的**，
第 i 个核读到的是同一帧第 i-1 个核写下的状态。这不是 bug，是当前的实现事实，
直接决定了这四个策略的失效模式形状。

### 6.1 动作空间

**A 组 · 移动**：dirX, dirY（期望方向）、boost（冲刺意愿 0..1）
**B 组 · 施力**：forceSlot（目标下标，-1 表示不施力）、forceX, forceY（期望加速度矢量）
**C 组 · 社会调制**：mod[0..3]，分别调制视野、个人空间、斥力、聚拢，每项 [-1,1]

### 6.2 RulePolicy（规则打分）：默认策略

```
urg   = 1 - e,          e = clamp01(s12)      // 紧迫度 = 1 - 速度归一化
align = d_i . h_hat                          // 与当前航向的对齐度
trust = 1 - 0.5*d,      d = clamp01(s16)      // 温度信任折扣

score_i = 1.0*trust*p_i + 0.8*align_i + 0.6*urg
```

选最高分候选，输出它的方向和 boost = urg。

**拥挤让速**（仅当感知到邻居时）：

```
boost *= 0.5 + 0.5*s_r,     s_r = clamp01(s18)
```

**失效模式**：

- **无食物等于完全静默**：候选全空时输出零方向、零 boost，没有任何探索项，核只能原地等死
- **紧迫度是伪能量**：1 - s12 只表示跑得慢，与真实能量无因果。静止且能量充足时 urg = 1（最大冲刺意愿）
- 高失真下 trust 最低只到 0.5，接近度项永远压不到 0，仍会按被污染读数扑向错误方向

### 6.3 HysteresisPolicy（滞回选择）

在 RulePolicy 骨架上加现任保护：

```
score_i = wP*p_i + wA*align_i       // 注意：缺紧迫度项
```

**两步选择**：

1. 找当帧最高分 best
2. 滞回判定：若现任 c 仍有效且 score_best <= score_c + gap（gap = 0.08），**继续选现任**

**失效模式**：

- **现任是全种群共享的**，核数大于 1 时，滞回语义被稀释成群体惯性
- gap 造成目标粘滞：食物消失时仍扑向已变差的目标
- 无紧迫度项，饿死和吃饱时行为完全一样

### 6.4 PerceptronPolicy（感知机）

```
Z_i = b_i + sum_{j=0..23} w_ij * s_j  +  sum_{j=18..23} w_ij * s_j
```

**第二个求和是独立追加的**，所以当 kDim = 24 时，**s18..s23 的贡献被计入两次**（等效权重 2w）。

输出（注意：**不是 sign**）：

```
a_x = clamp(Z_0, -1, 1)
a_y = clamp(Z_1, -1, 1)
boost = (Z_0 + Z_1 > 0) ? 0.5 : 0
```

**权重不可遗传**：perceptronSeed / perceptronScale 只在构造期用一次，此后恒定，
且全部个体共用同一组权重。所谓进化押注在权重上，指的是**你用 --perceptron-seed 扫参来选**，不是仿真内遗传。

**实测**：8 策略对比中 **6/6 seed 全灭**（全部灭绝在 tick 60-140，峰值核数 12-14，
即全生命周期只发生 0-2 次繁殖）。随机初值在 [-0.1, 0.1] 均匀、24 维叠加后 |Z| 远小于 1，
输出对输入几乎不敏感。

### 6.5 ThermalPolicy（趋温）

```
suit    = clamp01( 1 - |s17 - T_pref| / 0.5 )        // 温度适宜度
caution = 1 - clamp01(s16)                           // 失真规避因子
doubt   = 0.5 * wC * (1 - caution)

trustFood = 1/(1+doubt)
trustStay = 1 + doubt
stay_i    = d_i_hat . v_hat                          // 与当前航向的余弦

score_i = wP * p_i * trustFood
        + wT * suit * (0.5 + 0.5*stay_i) * trustStay
```

参数：wP = 1.0、wT = 1.2、wC = 0.8、T_pref = 0.5。

**关键设计**：s16 和 s17 是自身所在点的标量，对三个候选**完全相同**，
直接加分对 argmax 是常数。所以温度项被改造成**候选级**（乘 0.5 + 0.5*stay_i），
失真规避则通过 trustFood / trustStay 调节两个信号的相对强度。

**boost 门控（反直觉）**：

```
boost = (s16 > 0.5) ? 0.3 : 0
```

**高失真时反而给 0.3 的冲刺意愿**，这与头文件注释描述的降速方向相反。这是代码事实。

### 6.6 BanditPolicy（Hedge / EXP3-lite 双臂）

把 RulePolicy 和 ThermalPolicy 当两个臂，按历史回报做指数加权。

**混合输出**：

```
dir   = unitOrZero( wR*uR_hat + wT*uT_hat )
boost = clamp01( wR*ar.boost + wT*at.boost )
```

**环境回报**：

```
curProx  = max_j clamp01(s[6+j])
gain     = curProx - prevProx
speed    = clamp01(s12)

r_Env = clamp[-1,1]( 0.6*gain + 0.4*speed*(2*curProx - 1) )
```

**每臂信用分配**：

```
agree_i = clamp[-1,1]( u_i_prev_hat . a_prev )

pot_i   = sum_j p_j * max(0, u_i_prev_hat . d_j_prev_hat) / sum_j p_j

r_i = clamp[-1,1]( 0.5 * r_Env * agree_i + (pot_i - 0.5) )
```

**Hedge 更新（对数空间）**：

```
L_i   += clamp[-100,100]( eta * r_i )        // eta = 0.05, L_i(0) = ln 0.5
p_i    = exp(L_i - max L) / sum exp(L_k - max)
w_i    = max(p_i, 1e-6)                       // 反塌零地板
w_i   /= (wR + wT)                            // 重归一化
```

**势能项 pot 是必需的**：两臂体系下

```
agree_R - agree_T = (wR - wT) * (1 - uR_hat . uT_hat)
```

权重相等时两臂 agreement 恒相等，结果乘以同意度**永远打破不了 0.5/0.5 的对称**。
pot 只依赖上一帧感知，是每臂独立的反事实信号，提供打破对称所需的梯度。

**失效模式**：

- 回报是接近度变化而非真实能量收支，看不见移动与呼吸耗散
- **共享状态危害最大**：prevS_ 是同一帧上一个核的数据，跨核信用分配在物理上无意义
- 不施力

### 6.7 ForageBankPolicy（觅食-蓄能两态）

**能量代理量**（注意：这不是真实能量）：

```
e = 0.8 * s13 + 0.2 * (1 - s12)
```

s13 是离坐标缝多远，s12 是速度。**真实能量维 s21 完全不参与**。

**两态滞回**：

- e < 0.3，进入觅食态：全速冲最近食物，boost = 1.0
- e > 0.7，进入蓄能态：**逆着速度方向走**，boost = 0
- 中间带，保持上一帧状态

**死锁保护**：速度 <= 1e-9 时**强制进入觅食态**。
这是 P0 修复：核出生速度为 0，而出生点的代理量常落在 [0.3, 0.7] 中间带，
保持默认蓄能态会**永久静止**，导致本策略与 StubPolicy 逐帧完全相同。

**失效模式**：

- **能量代理不是能量**：s13 在环面上无物理意义
- 蓄能态方向是逆速而非回中心，s13 不含方位信息

### 6.8 RiskAversePolicy（EROI 能量回报率状态机）

唯一一个显式记账的策略。**风险度量是标量 EROI 的指数滑动平均**，
既不是方差、也不是分位数、也不是 VaR/CVaR。

```
gain   = 10.0 * max(0, s6 - prevProx)
budget = (1.0*v^2 + 0.05*(1 + 2.0*d)) / 32
obs    = gain / max(budget, 1e-6)

eroi   = 0.125*obs + 0.875*eroi             // alpha = 0.125, N = 32
eroi   = eroi * (1 - 0.5*d)                 // 温度折扣
eroi   = clamp[0,64](eroi)
```

**温度折扣的稳态效应**（容易忽略）：折扣乘在 EMA **之后**且每帧都乘，
所以它改变的是 EMA 的**不动点**：

```
eroi* = alpha * m * obs / (1 - (1-alpha)*m),    m = 1 - 0.5*d
```

d = 0 时 eroi* = obs；d = 1 时 m = 0.5、eroi* 约 0.111*obs。
**满失真把 EROI 稳态压到不失真时的约 11%**，这会把核永久打进 Conserve 态。

**三模式状态机**（滞回带 h = 0.1，E_high = 1.2，E_low = 0.6）：

| 当前 | 条件 | 迁移到 |
|---|---|---|
| Earn(2) | eroi < 1.1 | Mid(1) |
| Conserve(0) | eroi > 0.7 | Mid(1) |
| Mid(1) | eroi > 1.3 | Earn(2) |
| Mid(1) | eroi < 0.5 | Conserve(0) |

**Earn 与 Conserve 不能直接互转**，必须经过 Mid。初值 Mid。

**输出**：

- **Earn**：每帧更新方向指向最近食物，boost = 1.0
- **Conserve**：**每 3 帧才更新一次方向**，boost = 0.3；本帧无食物方向则输出零向量（不拿陈旧方向盲走）
- **Mid**：boost 线性插值 t = (eroi - 0.6)/0.6，boost = 0.3 + 0.7*t

**扫路施力**（仅 Earn 态、kPushBoost > 0 时）：找最近的球，若球方向与期望方向点积 >= 0.3（挡路），
施力方向 = unit(ball_hat + 0.5*e_hat)。

**失效模式**：

- **EROI 量纲不可比**：gain 是接近度差乘 10，budget 是 v^2/32 量级，
  obs 可以轻松超过 64 上限，eroi 长期饱和 64，**永久 Earn 态**
- **参数与真实行为层不同源**：策略里 kE = 10、kM = 1.0、kR = 0.05、kT = 2.0 是占位常量；
  行为层实际是 locomotionCost = 0.0002、respirationBase = 0.03、respirationK = 0.0004。
  函数形式相同，**数值完全不同**
- 增益只看候选 0，两 tick 间候选 0 换人会制造虚假增益

### 6.9 StubPolicy（空策略）

整个函数体是 return {}，零方向、零 boost、不施力、不调制。
它是默认保守契约的基准。**实测中它反而能量效率最高**。

### 6.10 八策略总览

| 策略 | 打分明细 | 施力 | 社会调制 | 实测存活 |
|---|---|---|---|---|
| **rule**（默认） | 接近/对齐/紧迫 | 无 | 拥挤让速（只读） | 0/6 灭绝 |
| hysteresis | 接近/对齐 加滞回 | 无 | 可选 mod[1] | 0/6 |
| perceptron | 24 维线性加饱和 | 无 | 无 | **6/6 灭绝** |
| thermal | 接近/温度乘航向 | 无 | 可选 mod[0,1,3] | 0/6 |
| foragebank | 两态滞回 | 可选拉球 | 可选 mod[0] | 0/6 |
| bandit | Hedge 双臂 | 无 | 可选 mod[3] | 0/6 |
| riskaverse | EROI 状态机 | 可选扫路 | 可选 mod[0,3] | 0/6 |
| stub | 无 | 无 | 无 | 0/6 |

**注意**：生产路径下所有可选的调制和施力强度**恒为 0**（没有 CLI 入口，装配时用默认参数）。
所以默认跑起来，只有移动通道是活的。

## 7. 行为：意图如何变成能量账

### 7.1 一帧七步

**步骤 1 · 写噪声**

```
A = 0.25 * v/(1+v)
d_x += A*(2*u1 - 1)
d_y += A*(2*u2 - 1)
```

A 随速度单调递增，上界 0.25。A = 0 时**一次随机数都不抽**。

**步骤 2 · 移动**

```
v_max_eff = maxSpeed * (1 + 0.5*boost)

v_tilde = d_hat * 60 + a_social        // 方向单位化后乘 moveK=60，叠加社会加速度

// 限加速（加速度模长上限 = maxAccel）
若 |v_tilde - v_prev| > a_max:
    v_tilde = v_prev + (v_tilde - v_prev) * a_max / |v_tilde - v_prev|

// 限速（只缩不放）
若 |v_tilde| > v_max_eff:
    v_tilde *= v_max_eff / |v_tilde|

v_t = v_tilde * damping                // 默认 1.0 = 无阻尼
p_t = wrap(p_prev + v_t)
```

> **转向的物理**：没有显式角速度上限。转向由每帧加速度模长 <= maxAccel 间接约束。
> 高速核无法急转（maxSpeed=300 时速度大，加速度只有 50，转弯半径巨大），
> 低速核可以。这是一个**涌现出来的**机动性约束。

**步骤 3 · 运动代谢**

```
loco = 0.0002 * v^beta * mu_terrain,     beta = 2.0
spend = min(loco, E)
```

水域内 mu = 1.8，否则 1.0。

**步骤 4 · 被动呼吸**

```
B = n_shield > 0 ? 0.03 / (1 + 0.35*n_shield) : 0.03

resp = (B + 0.0004*v^2) * (1 + 1.5*d) * dt
spend = min(resp, E)
```

d = 温度失真度。

**呼吸的完整经济含义**（这是生存压力的核心）：

| 状态 | 呼吸/帧 |
|---|---|
| 静止加适宜温度 | **0.03** |
| 静止加满失真 | 0.075 |
| 全速（v=300）加适宜 | 0.03 + 0.0004*90000 = **36** |
| 1 个护盾球加静止 | 0.03/1.35 = 0.022 |

**速度项的二次方是残酷的**：maxSpeed=300 的基因型在全速时每帧烧 36 能量，
而从蓝细菌吃一口最多拿到 0.15*(100-15)*rate。

**步骤 5 · 已删除**：进食分支整段删除，捕食在组合根执行。

**步骤 6 · 球控制**：见第 8 节

**步骤 6b · 内部动作触发**

每帧**无条件**抽一次 roll（无论是否触发都消耗 1 次 RNG）：

```
roll < p_act = 0.10

capRef = n.cap > 0 ? n.cap : 4*energyThreshold

产球: E > 0.6 * capRef
回收: E < 0.25 * capRef 且 球数 > 0
```

优先级：产球优先于回收。

**步骤 6c · 容量结算**

```
cap = 200 + 60 * n_resource
若 E > cap: 裁剪超出部分，dissipate("capOverflow")
```

**步骤 7 · 死亡**

```
若 E <= 0:
    left     = max(E, 0)
    耗散      = 0.7 * left          // dissipate("death")
    营养包    = 0.3 * left          // Carrion
    名下球全额耗散
```

### 7.2 产球与回收的具体账目

**产球**（deployBall）：

- 门槛：E > 8.0 且 balls.size < 3
- 扣 8.0 并 dissipate("deploy", 8.0)
- 若扣后 E > 10.0：再扣 10.0，球得 10.0，transfer(核 -> 球, 10.0)
- 球轨道角随机（1 抽），半径 = R_load(10) * (0.5 + orbitRadius/240)

**球类型选择**：当前无 Scout 球则产 Scout，否则产 Resource。
**Shield 球在生产路径上永远不会被产球逻辑创建**（只有 --config 或存档才有）。

**回收**（recycleBall）：取末位球

```
give = min( E_b * 0.5 * absorbPreference[t],  E_b )
loss = E_b - give

transfer(球 -> 核, give)
dissipate("recycle-loss", loss)
```

**默认 absorbPreference = 1.0** 时 give = 0.5*E_b，即**回收永远只拿回一半**。
这是吃掉电池换零食的真实代价，absorbPreference 基因因此是回收效率的直接选择对象。

### 7.3 繁殖

**门槛**：

```
k = energyThreshold * reproductionCostRatio
判据: E > k
```

**零和分割**：

```
E_亲 -= k
E_子  = 0.5 * k
耗散  = 0.5 * k        // reproduce-loss
```

**子代继承**：

- 全字段拷贝（含 genome），balls 与 detached_ 清空（球是亲代资产）
- genome 经**必然变异**（见第 9 节）
- 出生位置：亲代位置 + [-delta, delta]^2 方形均匀偏移，delta = 12
- digestCooldown = 0

**没有繁殖冷却**。唯一的时间约束是门槛本身：一次繁殖扣掉 k，需再攒回 k 才能生第二个。

**种群护栏**：aliveCount < maxNuclei = 1200。这是**性能护栏，不是生态承载力**
（承载力由能量收支自然决定）。

### 7.4 社会力（核与核之间）

**零能量转移**：只是加速度。这是 AMEND-1 明确划定的：核之间不做战斗、不做吸血。

**本帧生效值**（决策层 mod 调制表型，基因本身不改）：

```
x_eff = x_gene * (1 + 0.4 * clamp(mod, -1, 1))
```

对每个邻居 j（d 为环面最小距离）：

```
// 斥力
若 d < effSpace_i:
    a_i += effRepel_i * (1 - d/effSpace_i) * u_hat_{j->i}

// 聚拢
若 effSpace_i <= d < effSight_i 且 effCohesion_i > 0:
    a_i += effCohesion_i * (1 - d/effSight_i) * u_hat_{i->j}
```

**两式互斥**（else-if）。死核不施力也不受力。

**两阶段积分**：先对全体核算出所有加速度，再统一积分。
这消除了谁先动谁占便宜的顺序依赖，这是确定性的必然要求。

**重要缺失**：注释声称硬分离在 Simulation::step 里单独 pass，但**实际代码中没有这个 pass**。
minSeparation / repelK / forageK / forageRadius / wanderK / wanderTurnRate
六个参数**全部无消费者**。核之间可以完全重叠。

## 8. 球：器官、仓库与力场

### 8.1 两条车道

球有两种运动模型，由 r7Lane 标记：

- r7Lane = false：**极坐标轨道模型**（旧行为层，S18/S19/S20 语义）
- r7Lane = true：**世界积分车道**（v2.3.1 力学，组合根权威推进）

部署球和蓝细菌产球默认走 false；归属结算换主/收编的球会置 true。

### 8.2 球的负载半径

```
R_load(E) = 10 + 0.5 * max(E, 0)
```

**这是能量到几何长度的唯一映射**，线性关系。没有体积/密度换算。

| 球能 | 负载半径 |
|---|---|
| 0 | 10 |
| 60 | 40 |
| 120 | 70 |
| 300 | 160 |

**球越大越难控制**，这直接引出下一节的失控机制。

### 8.3 球控制增益与失控

```
G(d) = 1 / (1 + (d/h)^2),     h = handoffRadius = 60
```

| 球距核 | 增益 G |
|---|---|
| 0 | 1.00 |
| 60 | 0.50 |
| **120** | **0.20** 失控阈值 |
| 300 | 0.038 |
| 600 | 0.0099 |

G < 0.2 等价于 d > 2h = 120 即失控。
失控判据用的是**当前真实环距**，不是 b.radius。

**轨道模型（受控分支）**：

```
omega = G
theta += omega * dt

R_star = (10 + 0.5*E_b) * (0.5 + orbitRadius[t]/240)

r_new = r < R_star ? r + (R_star - r)*min(1, 0.3*affinity[t]*dt)
                   : r + (R_star - r)*min(1, 0.3*repelStrength[t]*dt)
```

**失控分支**：球按自己的速度飘，角速度保持 lastOmega，半径重新由环距计算。

**自然脱离**：当 E_b > detachEnergy = 120 时记入待脱离列表。
球脱离时**能量逐位不变，账面零操作**，核失去的是支配权，不是能量。

### 8.4 球的散热

**所有球每帧缓慢散热**（两个分支共用）：

```
drift = 0.0002 * r * 0.05 * dt = 1e-5 * r
```

r 是轨道半径。一个半径 70 的球每帧损失 7e-4 能量，
相比球能 120 这是极慢的（约 17 万帧掉一半）。设计意图是防能量坟场，不是惩罚存球。

### 8.5 球力场（世界积分车道）

**单个核对球 b 的加速度**：

```
// 径向弹簧，把球拉回轨道半径
a += u_hat * ( -affinity[t] * (d - R_star) * radialK * dt )

// 切向驱动（逆时针）
a += t_hat * ( affinity[t] * tangentialK * dt ),   t_hat = (-u_y, u_x)

// 近核排斥
若 d < nearRepelRadius:
    a += u_hat * repelStrength[t] * (1 - d/nearRepelRadius) * dt

// 跟随耦合
若 d_owner < detachRadius:
    a += u_owner_hat * ( -affinity[t]*(d_owner - R_star)*radialK*followCoupling*dt )
```

生产值：radialK = 0.05、tangentialK = 1.0、nearRepelRadius = 8、followCoupling = 4.0、followBoost = 1.5。

**球与球之间**：

```
// 短程排斥
若 d < r_rr(=6):
    a += u_hat * ballRepelK(=0.5) * (1 - d/r_rr) * dt

// 同宿主吸引
若 r_rr <= d < r_ar 且 同宿主:
    a -= u_hat * sameOwnerAttractK * (1 - d/r_ar) * dt
```

**同宿主吸引在生产路径上是关闭的**（sameOwnerAttractRadius = 0）。

**积分**：

```
v = (v + a*dt) * ballDamping(0.92)
若 |v| > v_max: v *= v_max / |v|
p = wrap(p + v*dt)

v_max = max( v_type,  v_核 * 1.5 )
```

类型限速：Resource 20、Scout 30、Shield 15。

### 8.6 归属结算

每颗世界车道球取 detachRadius = 60 内**最近**的存活核：

- 宿主不变，什么都不做
- 换主，对**原主**扣 lossCost = 0.2（限额支出，ball_loss），球直接交接（能量原样）
- 无主，进自由球池

**目标宿主已满 3 球时不交接也不惩罚**。

### 8.7 自由球

- 非世界车道：位置漂移加速度阻尼 0.99/帧
- **所有自由球**每帧按 E * 0.0002 散热（ballDrift）
- 拾取半径 adoptRadius = 18，按核序、球序收编
- 池上限 256，超限回收最老的蓝细菌源球（全额耗散）

## 9. 遗传：变异、选择与谱系

### 9.1 24 个基因及其真实作用

| # | 基因 | Init 区间 | Clamp 区间 | 真实作用 |
|---|---|---|---|---|
| 1-3 | affinity[0..2] | [0.1, 1.0) | [1e-4, 10] | 球径向弹簧速率 |
| 4-6 | orbitRadius[0..2] | [30, 200) | [10, 300] | 球轨道半径偏置 |
| 7-9 | absorbPreference[0..2] | [0.5, 1.5) | [0.1, 3.0] | 回收返还率 |
| 10-12 | repelStrength[0..2] | [0.5, 3.0) | [0.1, 6.0] | 球近距排斥 |
| 13 | maxSpeed | [30, 100) | [5, 300] | 移动限速 |
| 14 | maxAccel | [1, 20) | [0.5, 50] | 加速度上限加施力上限 |
| 15 | energyThreshold | [80, 200) | [20, 1000] | 繁殖门槛 |
| 16 | mutationRate | [0.01, 0.2) | [0.001, 0.5] | 变异步长 |
| 17 | cyanoPreference | [0, 1.0) | [0, 1] | 捕食意愿（0 = 严格不捕食） |
| 18 | cyanoDigestion | [0.1, 1.0) | [0.05, 1] | 转化率加消化冷却 |
| 19 | nucleusSightRadius | [40, 300) | [10, 600] | 社会感知半径 |
| 20 | nucleusPersonalSpace | [15, 80) | [5, 200] | 斥力半径 |

| 22 | nucleusCohesion | [0, 3.0) | [0, 10] | 聚拢倾向（0 = 独行） |
| 23 | forceRange | [30, 150) | [10, 400] | 可施力距离 |
| 24 | forceCostK | [0.005, 0.05) | [1e-4, 1.0] | 施力代价系数 |
| - | hue | [0, 360) | 环绕 | 谱系颜色 |

**关键**：24 个基因**全为线性量纲**，直接作为物理参数进入算式。
唯一的非线性表型映射是轨道半径偏置 0.5 + orbitRadius/240。

### 9.2 变异算子（唯一的进化算子）

```
Delta x_i = g_i * ( rho * (C_max_i - C_min_i) ) * kappa,     g_i ~ N(0,1)
```

- rho = 变异前的 mutationRate **快照**（所有参数共用同一个值）
- C_max - C_min = 该参数的 Clamp 区间宽度，**步长与合法域成正比**
- kappa = mutationCoefficient = 0.25（全局变异系数）

色相单独处理，**不乘** mutationRate：

```
Delta h = g * 8.0 * kappa
```

**Box-Muller 高斯**（每次恰消耗 2 次随机数）：

```
g = sqrt(-2*ln(u1)) * cos(2*pi*u2),     u1 = 1 - U 在 (0,1]
```

收尾固定执行 clamp 加 affinity 归一化。

**没有交叉/重组**。子代 = 父代拷贝 + 加性高斯扰动。这是唯一的遗传算子。

### 9.3 变异率的自指性

mutationRate **自己也会被变异**。否则进化会卡死在初始值：
低变异率的谱系产生高度相似的后代，若环境变化它们会一起死；
高变异率的谱系能探索但可能破坏好基因。**这个参数本身在进化**，这是设计上的精妙之处。

### 9.4 色相谱系

- 出生：h = 360*U，[0,360) 均匀
- 子代：h += g * 8.0 * 0.25 = g * 2.0（标准差 2 度）
- **色相不影响任何物理量**，只用于渲染和 trace 导出

**这就是为什么判据 4（谱系 hue 圆标准差 > 30 度）未达标**：
子代色相抖动很小（2 度），而种群在不断混合，圆标准差很难发散到 30 度。

**蓝细菌有独立的色相通道**（sigma = 20，大得多），与核色相互不相干。

### 9.5 选择的实际压力来自哪里

| 压力源 | 被选择的基因 | 机制 |
|---|---|---|
| 速度惩罚 | maxSpeed 下降 | 运动代谢正比 v^2 加转化率正比 1/(1+v/40) |
| 繁殖门槛 | energyThreshold 与 cap 匹配 | 门槛大于 200 必须囤球 |
| 捕食效率 | cyanoDigestion 上升 | 转化率加冷却双重收益 |
| 捕食意愿 | cyanoPreference | 0 等于完全不捕食（饿死）；1 等于吃满 |
| 回收效率 | absorbPreference 上升 | 回收返还 = 0.5 * preference |
| 温度适应 | 无直接基因 | 温度只压制所有人，不产生分化 |
| 社会性 | nucleus 四参数 | 聚拢等于共享食物源但也竞争 |

**注意反选择陷阱**：migrationBonus（迁移回报）实验过 0.6，
结果 **6000 tick 撞 600 护栏、hue 5.4 度更差**，奖励太强反成快等于多吃的新单调压。
这类看起来美好实际有害的机制在本项目中多次记录在 LOG。

## 10. 温度：失真如何惩罚所有人

### 10.1 温度场

**温度场没有时间演化**，没有扩散项、没有衰减项、没有边界松弛。
场 = 基线 + 静态高斯源叠加，构造期生成一次，此后只读。

```
sample(p) = clamp01( baseline + sum_k A_k * exp(-q_k) )
q_k       = |Delta_k|^2 / (2 * R_k^2)
```

随机撒源（sourceCount = 3，每源 4 抽）：

```
x = U1 * W
y = U2 * H
A = -0.4 + 0.8*U3        // [-0.4, 0.4)，正是热源、负是冷源
R = 100 + 200*U4         // [100, 300)
```

默认 3 个源，构造期消耗 12 次随机数。

### 10.2 失真度

```
distortion(p) = clamp01( |sample(p) - T_pref| * distortionK )
```

默认 T_pref = 0.5、distortionK = 2.0。

| 温差 | 失真度 |
|---|---|
| 0 | 0 |
| 0.1 | 0.2 |
| 0.25 | 0.5 |
| >= 0.5 | **1.0（饱和）** |

### 10.3 温度影响的两条路径

1. **感知**：s16 = 失真度，读噪声放大 (1 + 3.0*d)，最多 4 倍
2. **呼吸**：1 + 1.5*d，满失真时呼吸贵 2.5 倍

**没有 Q10 公式**。温度效应是线性乘性因子，不是 Q10 幂律。

### 10.4 温度的生态含义

温度**不产生分化**，它对所有核一视同仁，只是整体加税。
站在冷源/热源上的核：感知更糊（噪声 4 倍）、呼吸更贵（2.5 倍）、EROI 被压到 11%。
所以理性行为是**避开温度异常区**，但由于光照是全局的，高温区并不提供补偿性收益。
**温度目前是一个纯粹的惩罚项，不是一个资源梯度**。

## 11. 账本：为什么能量永远守恒

### 11.1 恒等式

```
injected_total - dissipated_total = sum(所有活体能量)
```

**三个计数器**：injected（注入）、dissipated（耗散）、transferred（转移流量）。

transfer **只累加流量，不改总量**，搬运不改变能量的存在性。

### 11.2 活体能量和的精确组成

```
sum = sum over 存活核 n ( n.E + sum_{b in n.balls} E_b + sum_{b in n.detached_} E_b )
    + sum over 自由球 E_b
    + sum over 营养包 E_c
    + E_cyano
```

**死核不计入**，但它的 carrion 在尸体压缩前已被搬到组合根容器，故仍计入。

### 11.3 三层审计

每帧末尾执行：

1. **全局恒等式**：容差 1e-9 * max(1, injected)
2. **蓝细菌收支闭合**：|Delta E_cyano 减 (photo 减 metab 减 repro)| <= 1e-6*max(1, |E_before|)
3. **尸体流水闭合**：|carrionIn 减 carrionOut| <= 1e-9*max(1, carrionIn)

**失败行为**：runTo 立即返回 false，CLI 置 auditFailed，先写完本帧输出再 break，退出码 3。

### 11.4 全部耗散原因

| reason | 触发 | 量 |
|---|---|---|
| locomotion | 运动代谢 | 0.0002*v^2 |
| respiration | 被动呼吸 | (B + 0.0004v^2)(1+1.5d) |
| deploy | 产球固定成本 | 8.0 |
| recycle-loss | 回收未返还部分 | E_b*(1 - 0.5*pref) |
| reproduce-loss | 繁殖差额 | 0.5*k |
| applyForce | 施力代价 | k*|a|^2 |
| ballDrift | 球散热 | 见 8.4 |
| capOverflow | 超容量裁剪 | E - cap |
| death | 死亡 70% 加球能全额加尸体溢出 | 见 7.1 步骤 7 |
| ball_loss | 换主失主惩罚 | 0.2 |
| cyanoMetabolism | 蓝细菌代谢 | 0.02/节点 |
| cyanoReproduction | 分裂损耗 | 20/次 |
| cyanoBallExpire | 自由球池溢出 | 该球全额 |
| event:winter / event:plague | 事件扣血 | 见 12 节 |

| 4 | 爆发 | 4.0 | 2.65 |

**这是总能量水位的主旋钮**。爆发档下节点净增长是标准档的 4 倍，
能量注入远超消费能力，总能量单调上涨，判据 1 失败。

### 12.2 事件卡（免费、无冷却）

| 事件 | 效果 | 生态意图 |

## 13. 生态判据：怎么判断它健康吗

tools/analyze.mjs 自动判定 6 条硬判据。

### 13.1 判据 1：能量紧平衡

```
|slope| * windowTicks / mean(windowTotal) < 0.15
```

**测量窗口是末 30%**（不是全窗口）。原因：1024x1024 世界里开局是半空世界，
种群要数千 tick 向承载力爬坡。全窗口斜率测的是**殖民速率**，不是平衡漂移。

**DEFER 语义**：若末 30% 的核数趋势 |slope| > 5%/kt（种群仍在爬坡），
判据输出 **DEFER（未稳态）** 而非 FAIL。用错尺子量未稳态系统得到的 FAIL 是噪音。

### 13.2 判据 2：种群波动

```
末 20% 核数 CV 在 [0.05, 0.6]  且  末态核数 > 0
```

不能单调涨到上限然后平台，也不能单调跌到 0。必须是上冲、回落、再上冲。

### 13.3 判据 3 到 6

| # | 判据 | 数据源 | 现状 |
|---|---|---|---|
| 3 | 24 参数中 >=18 个末态 std > 初态 std * 0.3 | genome | 需 --trace-genome |
| 4 | hue 圆标准差 > 30 度 | genome | **未达标（实测 9.9 度）** |
| 5 | corr(nuclei, cyano) < -0.2 或滞后过零 | series | 可算 |
| 6 | 调控 20k tick 后目标基因变化 > 10% | genome x2 | 需 baseline |

**没有 genome 数据时判 3/4/6 输出 SKIP（不是 FAIL）**。SKIP 是数据缺失，不是生态失败。

### 13.4 八策略实测对比

E4 报告（20000 tick x 6 seed x 8 策略 = 48 次运行）：

| 策略 | 灭绝次数 | total_energy 均值 | sd |
|---|---|---|---|
| **stub** | 0/6 | **12982** | 209 |
| foragebank | 0/6 | 12691 | 281 |
| riskaverse | 0/6 | 12560 | 114 |
| rule | 0/6 | 12528 | 357 |
| hysteresis | 0/6 | 12507 | 275 |
| bandit | 0/6 | 12490 | 249 |
| thermal | 0/6 | 12479 | 220 |
| **perceptron** | **6/6** | 9093 | 71 |

**最反直觉的结果：什么都不做的 StubPolicy 能量效率最高。**
原因：所有主动策略都在移动，而移动要付 0.0002 v^2 代谢加速度项呼吸。
StubPolicy 原地不动，只付基础呼吸 0.03/帧，靠蓝细菌自己产的球被捡（或者干脆不吃）。

**perceptron 的全面灭绝**：随机权重在 [-0.1,0.1] 均匀、24 维叠加后 |Z| 远小于 1，
输出方向对输入几乎不敏感，核乱走，饿死。峰值核数 12-14，全生命周期只繁殖 0-2 次。

**报告自身的局限**：每格单次运行、seed 只有 6 个、
7 个幸存策略的 total_energy 排名在 sd 量级内**统计上不可区分**。
而且该报告依赖的 kMaxNuclei = 24 硬上限在当前源码中已删除。

## 14. 真相清单：源码里没有的东西

这一节是防止误读的。以下机制**在代码里不存在**，尽管注释或文档可能提到：

| 机制 | 真相 |
|---|---|
| 核的质量 / 半径 / 朝向 / 年龄 / 谱系号 | **不存在这些字段**。体型只由 cap 代表 |
| 交叉 / 重组 | **不存在**。唯一遗传算子是加性高斯变异 |
| 核之间的能量转移 | **不存在**。社会力只产生斥力/聚拢，零能量转移 |
| 核战斗 / 避战 | AMEND-1 整链路删除，24 参数中无对应项 |
| Q10 温度标度 | **不存在**。温度效应是线性因子 (1 + 1.5d) |
| 感知能量代价 | **不存在**。感知只花 CPU 和 RNG，不花能量 |
| 温度场的时间演化 | **不存在**。静态场，无扩散/衰减 |
| 空间光照异质性 | **不存在**。全图一个标量 |
| 核硬分离 pass | 注释声称存在，**实际未实现**。minSeparation 等 6 参数无消费者 |
| kReproTriggerFrac | 常量声明但**未使用** |
| conversionExponent | 参数传入但被显式丢弃 |
| childEnergyRatio / reproductionOffset | 参数存在但**无消费者**，行为层用硬编码常量 |
| 感知机权重遗传 | **不存在**。权重构造期固定，全种群共享同一组 |
| ForageBank 的真实能量感知 | **不存在**。用的是 s13（坐标缝距离），不是 s21 |
| RiskAverse 的方差/分位数风险度量 | **不存在**。是标量 EROI 的 EMA |
| 自由球被核吃掉 | **不存在**。核只能拾取（adopt）球，不能吃球能量 |
| Shield 球的生产路径 | **不存在**。产球逻辑只造 Scout 和 Resource |

**还有两个"存在但共享"的坑**：

1. **策略实例全种群共享**：所有核用同一个策略对象。
   有状态策略（Hysteresis/ForageBank/Bandit/RiskAverse）的记忆是**全种群滚动状态**，
   不是每核独立。核数 > 1 时这些策略的个体记忆语义不成立。
2. **TargetList 只含自由球**：注释说"自由球 + 自己的球"，但实际只遍历 freeBalls_。
   **自己名下的轨道球永远不在施力清单里**。

### 最后三个心法

**一、这个系统唯一的真负反馈是自遮光。**

其他一切上限（cyanoMaxNodes、maxNuclei、自由球池 256）都是性能护栏，不是生态机制。
想让生态自然，把 shadeK 调对，然后**别动护栏**。

**二、速度基因的取舍是分化的核心。**

快等于覆盖大、转化率低、代谢贵；慢等于吃得香、覆盖小、省能。
这个三角形由三个独立公式共同定义（运动代谢 v^2、呼吸 v^2、转化率 1/(1+v/40)），
改任何一处都会改变选择方向。

**三、确定性是你的显微镜。**

同 seed 跑两次逐字节一致。这意味着你可以做**严格的单变量对照实验**：
改一个参数，跑 20000 tick，diff 两次的 stats.csv，**所有差异都归因于那一个改动**。
这是这个模拟器最被低估的能力，它不是游戏，是可复现的生态实验室。
