# ADR-005：蓝细菌取代食物（单一生产者模型）

日期：2026-10-31
状态：已采纳（用户决定）
决定者：用户

## 背景

agentsim 初版沿用了旧版（v2.3.1）的"抽象 Food"作为第一营养级：
每 tick 定额再生（`kFoodRegrowPerTick = 2`），与核的进食构成闭环。
S22 蓝细菌实体化后，出现了**两个生产者并存**的过渡态：
人工撒食的食物 + 光合自养的蓝细菌。这带来三个问题：

1. **能量流不自然**：自然界是单向的 光→生产者→消费者，不存在"凭空撒食"。
2. **蓝细菌悬空**：光合注入的能量没有消费者（核只吃食物），
   实测总能量从 1800 涨到 58262 且持续上升，蓝细菌成为无底洞。
3. **S23 无法验证**："仅靠蓝细菌自身分裂仍维持种群"这一判据，
   在人工撒食常开的情况下没有意义。

## 选项

1. **维持双生产者**：食物与蓝细菌并存。问题 1/2/3 都不解决。
2. **蓝细菌取代食物**：食物只做启动库存，`regrow` 默认关闭。
   能量流变为 光 → 蓝细菌（光合） → 核（捕食） → 自由球（衰减回流）。
3. **食物与蓝细菌按比例共存**：regrow 系数可调。复杂度高，
   且"两个生产者"在自然界没有对应物。

## 决定

**选项 2**。具体变更：

- `FoodConfig::regrow` 默认 **false**（原 true）。
- 新增 `--regrow` 显式恢复旧行为；`--no-regrow` 保留为冗余别名（兼容已有脚本）。
- 捕食接线（核吃蓝细菌）同步上线：`kGrazeChance=0.25`、`kGrazeFraction=0.04`、
  `kGrazeConversion=0.6`，经能量平衡账标定（供给 ≈38/tick vs 需求 ≈10/tick）。

## 后果

### 正面
- S23 验证通过：20k × 3 seed（42/7/123）无人工撒食，nuclei=24（顶满上限），
  `audit=ok`，第一营养级未断裂。
- 能量流单向、可解释；蓝细菌种群由"光合 vs 捕食"共同调节，出现真实的生态张力。
- `--regrow` 保留了回到旧行为的逃生门。

### 负面（已知并接受）
- 总能量水位升高（26k~29k）：核数顶在 `kReproCap=24` 封死消费，
  过剩产出堆积在蓝细菌节点与自由球池。属生态调参问题，不是缺陷。
- 初始食物耗尽后（约几百 tick）`food` 计数归 0，旧脚本的 food 相关断言会失效。
- R8 红队发现的"尸体占坑"（P1）曾加剧吃绝风险，已随尸体压缩修复。

### 中性
- `--no-regrow` 与 `--regrow` 同时存在时后者胜出（顺序无关的覆盖语义）。

## 可逆性

**高**。`--regrow` 一个开关即可回到双生产者模型；Config 默认值一行可改。

## 关联

- ADR-002（食物再生与账本归属）：其"每 tick 定额再生"结论被本决定**部分推翻**，
  该 ADR 的账目机制（injectPrimary 记账）仍然有效。
- S23（成功标准）与 T22/T25 任务卡。
- 红队 R8：其"能量死锁/尸体占坑"发现是本决定能落地的先决条件。
